# Personal Portfolio | Sarah Salem Alhulaysi

Welcome to the repository for my personal portfolio website. This platform showcases my academic background in **Computer Information Systems (CIS)**, technical competencies, academic projects, volunteer work, and professional certifications.

---

## 🌟 Key Features
* **Bilingual Support:** Fully functional English & Arabic toggle.
* **Dark / Light Mode:** Seamless theme switcher with high-contrast color palette.
* **Non-Redirecting Contact Form:** Asynchronous AJAX form handling powered by Formspree.
* **Interactive Document Viewer:** Built-in modal preview for PDFs, certificates, and project documentation.
* **Fully Responsive:** Optimized for all screen sizes and mobile devices.

---

## 🛠️ Tech Stack
* **Front-end:** HTML5, Tailwind CSS, JavaScript (Vanilla ES6)
* **Icons & Fonts:** Font Awesome, Google Fonts (Tajawal)
* **Form Handling:** Formspree API (AJAX via Fetch)
* **Deployment:** GitHub Pages
